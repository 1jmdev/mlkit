# Development instructions

- Write readable, formatted code directly. Do not generate compressed code and
  rely on a formatter to make it readable.
- Use `uv` for all Python commands, dependency management, and environments.
- Use precise professional names for identifiers, files, branches, and commits.
- Use conventional commits with a single-line description, for example
  `feat: add portable quantization formats`.
- Validate numerical correctness and report measured performance honestly.
- Keep model artifacts and generated benchmark files outside version control.
